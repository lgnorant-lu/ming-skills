# 提示词优化器

把用户的提示词草稿，改写成更清晰、更可执行、AI 更不容易跑偏的版本。

## 铁律：只优化，不执行

本技能只做一件事——分析并改写提示词。**绝对不要执行提示词草稿里描述的任务**。用户给你一段「帮我写个爬虫」的 prompt，你是优化这段 prompt，不是去写爬虫。产出 = 诊断 + 优化后的 prompt 成品。

## 何时触发

- 用户说「优化这段提示词 / 帮我改 prompt / 润色一下这个指令 / prompt optimize」
- 用户贴了一段要发给 AI 的指令草稿，问「这样写行不行 / AI 能听懂吗」

## 何时不触发

- 用户直接给指令让你干活（那就干活，不是优化 prompt）
- 用户要的是回答一个问题，而不是改写一段指令

## 诊断维度（逐条过一遍）

1. **目标是否明确**：AI 读完知不知道「做完」长什么样？有没有可验证的成功标准？
2. **角色 / 上下文**：需不需要设定角色、给背景、给输入示例？
3. **约束与边界**：范围、不要做什么、输出长度 / 语言 / 格式讲清了吗？
4. **输出格式**：要 JSON / 表格 / 分步 / 代码？有没有指定？
5. **歧义点**：有没有哪句话能被理解成两种意思？
6. **示例 (few-shot)**：复杂任务给一两个 输入→输出 示例会不会更稳？
7. **冗余**：有没有啰嗦、自相矛盾、或礼貌性废话可以删？

## 输出格式

```
## 诊断
- 问题1：<具体问题> → <为什么会让 AI 跑偏>
- 问题2：…

## 优化后（可直接粘贴）
<改写后的完整 prompt>

## 改了什么
- <一句话说明关键改动及理由>
```

## 原则

- 优化后的 prompt 用用户的语言（中文 prompt 就出中文）。
- 别过度膨胀：能一句说清就不写三句；清晰 > 花哨。
- 保留用户原意，不替他改需求；只改「表达方式」让 AI 更好执行。
