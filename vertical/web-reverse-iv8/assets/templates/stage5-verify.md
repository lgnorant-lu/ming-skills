### 6.2 参数溯源表(强制,v9.17 新增)

> 规则见 [stage4.md](../workflow/stage4.md) §5.3.1 Step 2 + "职责边界"。skill 只逆向算法,被加密数据由用户提供。本表告诉用户每个输入参数从哪拿/怎么生成。**方案 1 + 方案 2 共同必填**。

| 参数名 | 来源类型 | 用户获取方式 | 失效周期 | 备注 |
|--------|---------|-------------|---------|------|
| (如 lot_number) | HAR 接口返回 | 从 /api/lottery 响应 JSON 取 lot_number 字段 | 会话级 | 一次性获取复用 |
| (如 passtime) | 用户操作 | 从 HAR 请求 body 的 trajectory 数组计算 | 每次请求重新获取 | 用户操作产生 |
| (如 useragent) | trace 字段 | 从 trace stats 取 navigator.userAgent 基准值 | 长期有效 | 指纹对齐时需匹配 |
| (如 iv) | 浏览器 API 生成 | 用户用 `os.urandom(16)` 等价生成 | 每次请求重新获取 | 替代 crypto.getRandomValues |
| (如 timestamp) | 运行时生成 | 用户用 `int(time.time() * 1000)` 等价生成 | 每次请求重新获取 | 替代 Date.now() |
| (如 app_key) | 固定常量 | 硬编码 "xxxxx" | 长期有效 | 代码内常量 |
| (如 msToken) | HAR 接口返回 | 从服务器实时签发的响应取值 | 短期(分钟级) | 5-10 分钟过期,需定期刷新 |
| ____ | ____ | ____ | ____ | ____ |

> 来源类型枚举:HAR 接口返回 / trace 字段 / 用户操作 / 固定常量 / 浏览器 API 生成 / 运行时生成
>
> 失效周期枚举:长期有效 / 会话级 / 短期(分钟级) / 每次请求重新获取 / 自定义(需说明)

> ⚠️ **指纹值参与加密运算检查**:若加密算法读取了 `navigator.userAgent` / `location.href` / `document.cookie` / `screen` 分辨率 / Canvas 指纹 / WebGL 指纹等指纹字段,且该值进入加密输入,必须在参数溯源表中列出该字段,并在方案 2 iv8 补环境时用 `environment` 参数与 HAR 真实值对齐。详见 [iv8-env-patching.md](../modules/iv8-env-patching.md) "第三步补:指纹值参与加密运算"。
