# Sources & Benchmark References — 文档视觉与排版金标准

## 1. 理论与排版金标准
- **GitHub Flavored Markdown (GFM) Spec**:
  - Alert 容器规范: `> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`
  - `<picture>` 与 `prefers-color-scheme` 深浅色自适应规范
- **W3C 国际化排版标准**:
  - 中文排版需求 (Requirements for Chinese Text Layout): 汉字与西文字符间隙、标点挤压与全半角法则
- **W3C Progressive Disclosure 原则**:
  - `<details>` 与 `<summary>` 的语义化折叠，保持首屏信噪比

## 2. 业界顶级开源 README 标杆对照
