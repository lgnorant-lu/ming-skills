# Scene delta — 工具市场 / 插件平台型 (Marketplace & Platform)

市场与平台类仓库的核心矛盾是：**终端安装者只想一行命令装完走人，而生态作者需要理解复杂的规范**。必须通过严格的视觉层级与入口分流解决。

---

## 1. 骨架规范（<= 200 行标准动线）

```markdown
# 项目名称
一行人话：解决了什么平台的什么核心痛点。

[首屏单行指标] 核心数据 · 更新频率 · 分发机制 · 零限流保障

[产品截图] 真实 Web GUI 插件市场界面 (非概念海报)

## 复制即用
官方 CLI 单行命令 + 备用脚本说明
> [!WARNING]
> 针对远程安装脚本的信任边界提示。

## 在设置页里做什么
5 步以内的直观图文操作流 (安装/传参/更新/已安装)。

## 和自己搜 GitHub 差在哪
单张高密度能力矩阵表（分发速度、版本对比、安全沙箱、类型嗅探），严禁拆分两张同义表。

## 插件作者如何被收录
三行说明收录机制，核心开发指引直连 STANDARD.md。

<details>
<summary>工作原理与架构 (Mermaid)</summary>
流程图与数据流简述。
</details>

<details>
<summary>HTTP 接口与本地存储结构</summary>
完整的 API 表与 ~/.dsh/ 目录树。
</details>
```

## 2. 真实活体夹具：DSH-Plugins-Marketplace 改造前后对照

| 维度 | 原版问题 (AI 模板风) | 改造后规范 |
|---|---|---|
| **标题装饰** | `[Emoji] 核心优势`, `[Emoji] 一键安装`, `[Emoji] 使用方法` | 彻底移除 Emoji，直接用任务名：`复制即用`, `在设置页里做什么`, `和自己搜 GitHub 差在哪` |
| **首屏徽章** | 8 个 Shields.io 彩色徽章横向通铺 | 精简为 3 个：DeepSeek Harness 生态、License、最新版本 |
| **指标呈现** | 4 列 HTML 嵌套表格，移动端易碎 | 单行中圆点分隔：`9500+ DSH 插件 · 20000+ 通用 Skills · 2 小时增量同步 · 0 API 限流` |
| **内容重复** | `核心优势` (8行表) 与 `功能特性` (25点列表) 严重同义反复 | 合并为单张「能力对照表」，删除所有营销套话 |
| **源码体积** | 341 行，包含大量长表格与未折叠细节 | 控制在 160 行左右，长接口表与目录树放入 `<details>` 或 `docs/` |
