# Scene delta — CLI / 命令行工具 (Command Line Interface)

CLI 工具的核心诉求是：**最快让开发者在终端中跑起来并看到输出结果**。

---

## 1. 骨架规范

```markdown
# 工具名
一行说明：专为谁打造的高性能命令行工具。

[一行安装命令] curl / cargo / brew / npm

[终端录屏或高对比度输出代码块]

## 快速上手
最常用的 3 个子命令示例，带真实参数与输出注释。

## 命令与退出码参考
单张表格：命令/flag、退出码 (0/1/2) 含义。

## 环境变量与配置
配置项与默认值。
```

---

## 2. 禁令与注意事项
- 严禁在第一屏前放置超过 1 段解释性散文；
- 严禁在每个子命令标题前添加表情符号；
- 终端代码块必须指定语法高亮（如 `bash`, `console`）。
