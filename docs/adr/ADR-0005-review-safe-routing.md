# ADR-0005: 审阅安全路由与显式可用性

- Status: Accepted
- Date: 2026-09-06
- Supersedes: ADR-0001 中固定四包预算与召回即完整性的运行约束；ADR-0002 的 Node 18 运行时基线。其余职责分离原则保留。

## Context

现场审阅发现：分类置信度授予建单许可、否定点名误激活、只读请求变为实施、配方缺失与停用条目不可见。既有黄金候选测试通过仍能复现这些错误。管理测试还会写真实 manifest 并在 DryRun 中 fetch。

## Decision

RouteDecision 升级为 v2，mode 显式区分审阅、解释、规划和实施。分类与权限分离，adapt 永不授予 case-init；未知/v1 控制契约安全退回，不维护未经确认的双版本执行逻辑。

保留策划型规则和现有目录，构建读取 registry 与入口身份生成 availability。构建是管理操作，路由只读同包清单。使用 Node 22+；管理构建需要 PowerShell 7。测试默认隔离，跳过与通过分开，严格门禁不允许环境跳过。

已有 deployable 正文是维护内容，重建只补资源，不覆盖正文。上游正文更新需要显式差异审阅，不靠自动复制替换。私有资产与个人配置不因迁移需求默认公开。

## Consequences

消费 v1 的适配器必须与脚本和清单一起升级。规则分类仍有复杂自然语言盲区；availability 是构建快照而非现场权限或依赖证明。暂不实现多 Agent 调度、完整语义检索及跨客户端效果评估，后续按实际失败案例扩展。
